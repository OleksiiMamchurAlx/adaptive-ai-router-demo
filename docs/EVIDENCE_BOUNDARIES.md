# Evidence boundaries

| Material | Provenance | What it establishes |
|---|---|---|
| 16 evidence-library tests | Existing portfolio source, rerun for this publication | Bounded SQL, validation, export, backup and calculation behavior |
| 4 portable-demo tests | New publication-stage implementation | Controlled post-commit interruption, repeated export and safe refusal |
| Prior MCP recovery summary | Sanitized local test record | One deterministic tool execution and two resume/export operations in the earlier private environment |
| Prior policy comparison | Historical controlled experiment summary | 12 paired holdout tasks; baseline 6 accepted, candidate 8; only one route change |

The policy result is **INCONCLUSIVE**: limited route diversity, a small sample and variation even on the same route prevent attributing an improvement to routing. The 24 executions are 12 pairs, not 24 independent tasks. No automatic promotion followed.

Earlier transcript fixtures tested supplied text, not speech recognition. Provided-source tasks did not establish live browsing; computer-assistant fixtures did not establish live desktop control.

Original private evidence remains separate. This repository deliberately does not contain the full production router, working databases, local model weights, provider credentials or private traces. A sanitized summary is not a substitute for a portable executable test; both are labelled accordingly.

The current portable example preserves failed and unknown outcomes rather than interpreting them as success. A verifier error is unknown, not a negative training label.
